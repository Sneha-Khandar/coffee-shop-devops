# Coffee Shop Web Application - DevOps Project

A simple Coffee Shop web application used to practice basic DevOps tools and deployment concepts.

## Project Overview

This project focuses on applying basic DevOps practices to a web application using Linux, Docker, and Jenkins. The application was containerized using Docker, and Jenkins was used to practice a basic CI/CD workflow.

## Technologies Used

- HTML
- CSS
- JavaScript
- Linux
- Docker
- Jenkins
- Kubernetes (Basic Pod practice)

## DevOps Implementation

### Docker
- Created a Dockerfile for the web application.
- Built a Docker image for the application.
- Created and ran a Docker container.
- Practiced basic container management.

### Jenkins
- Used Jenkins for basic CI/CD workflow practice.
- Connected the project with the build/deployment workflow.
- Practiced automated build and deployment concepts.

### Kubernetes
- Practiced basic Kubernetes Pod concepts.
- Learned how containers can be deployed and managed using Pods.
